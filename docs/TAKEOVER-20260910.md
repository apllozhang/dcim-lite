## 集成测试用例（P0 修复的验收标准）

1. **同 U 位并发上架恰一胜**（EXCLUDE gist + 预检）
2. **20 路并发批准同一审批单恰一次生效**（决定与副作用严格一次，履历恰一条）
3. **批准失败回滚保持 PENDING**——目标 U 位被占时批准 409，审批单与设备状态完整回滚（事务原子性直接证明）
4. **导入提交中途失败零残留**（按名搜索无残留）+ **草稿回填可重试**（token 不因失败作废）
5. 乐观锁 version 过期 → 409 RESOURCE_VERSION
6. 软删除后同编码可复用（部分唯一索引）
7. 8 路并发降级第二管理员恰一胜（行锁 + 乐观锁；降级唯一管理员被 LAST_ADMIN 正确拒绝）
8. 在位机柜删除保护 409 HAS_CHILDREN

## 本批发现并修复的产品缺陷

- **审计 jsonb 写入失败**：`audit_logs.before/after_json` 为 jsonb 列，空字符串非合法 JSON 导致每条审计插入失败（此前的手工审计同样受影响且被静默吞掉）。改为可空指针列。**这个 bug 是集成测试跑出来的——之前没有任何测试能发现它。**
